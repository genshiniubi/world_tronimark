# 列表、字典与集合

## 你会学到
- list 的下标、切片、append
- dict 的键值查找与 `get`
- set 去重
- 列表/字典推导式

## 核心概念
列表适合有序序列；字典适合按键查找；集合适合去重和集合运算。

```python
counts = {}
for word in words:
    counts[word] = counts.get(word, 0) + 1
```

## 常见坑
- 字典的键必须可哈希，列表不能做键。
- 遍历字典时不要同时增删键。
- 排序字典项要用 `items()`。

## 练习建议
先问“我需要按位置还是按键访问”，再选容器。
