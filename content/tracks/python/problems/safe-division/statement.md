# 安全除法

> 金融账单 · 12 分钟 · 知识点：py-exceptions

## 情景

一个报表工具需要处理用户输入的除法。输入可能是非数字，也可能除以 0，程序不能崩溃。

## 任务

计算 a / b，保留两位小数；任何非法输入或除零都输出 ERROR。

## 输入格式

一行两个字符串 a 和 b。

## 输出格式

成功输出结果，失败输出 ERROR。

## 样例

### 样例 1

**输入**

```text
10 4
```

**输出**

```text
2.50
```

### 样例 2

**输入**

```text
10 0
```

**输出**

```text
ERROR
```

### 样例 3

**输入**

```text
abc 2
```

**输出**

```text
ERROR
```

## 数据范围

输入长度不超过 100。

## 知识点

`py-exceptions`
