# 斐波那契生成器

> 科学计算 · 15 分钟 · 知识点：py-generators

## 情景

数学小组想研究斐波那契数列。为了避免一次性占用大量内存，他们希望用生成器逐个产生数字。

## 任务

实现生成器 fibonacci(n)，依次产生前 n 个斐波那契数。

## 输入格式

一行一个整数 n。

## 输出格式

一行 n 个整数，用空格分隔。

## 样例

### 样例 1

**输入**

```text
5
```

**输出**

```text
0 1 1 2 3
```

### 样例 2

**输入**

```text
1
```

**输出**

```text
0
```

## 数据范围

1 ≤ n ≤ 100000。

## 知识点

`py-generators`
