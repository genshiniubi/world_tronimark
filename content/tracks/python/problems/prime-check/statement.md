# 素数判断

> 科学计算 · 15 分钟 · 知识点：py-functions、py-loops

## 情景

在生成实验编号时，需要跳过合数。请实现一个可靠的素数判断函数。

## 任务

判断给定的正整数是否为素数。

## 输入格式

一行一个整数 n。

## 输出格式

是素数输出 YES，否则输出 NO。

## 样例

### 样例 1

**输入**

```text
7
```

**输出**

```text
YES
```

**解释**：7 只能被 1 和自身整除。

### 样例 2

**输入**

```text
1
```

**输出**

```text
NO
```

### 样例 3

**输入**

```text
9
```

**输出**

```text
NO
```

## 数据范围

1 ≤ n ≤ 10^12。

## 知识点

`py-functions` · `py-loops`
