# 汇率换算

> 金融账单 · 8 分钟 · 知识点：py-io、py-types

## 情景

出国旅行前，你需要快速估算手里的人民币能换多少美元。汇率表示 1 美元需要多少人民币。

## 任务

按汇率把人民币换算成美元，保留两位小数。

## 输入格式

一行两个数：人民币金额 cny、汇率 rate（1 美元兑多少人民币）。

## 输出格式

一行一个实数，表示美元金额，保留两位小数。

## 样例

### 样例 1

**输入**

```text
720 7.2
```

**输出**

```text
100.00
```

**解释**：720 ÷ 7.2 = 100。

### 样例 2

**输入**

```text
100 8
```

**输出**

```text
12.50
```

## 数据范围

0 ≤ cny ≤ 10^9，0.01 ≤ rate ≤ 100。

## 知识点

`py-io` · `py-types`
