# 带缓存的斐波那契

> 算法竞赛 · 20 分钟 · 知识点：py-decorators、py-functions

## 情景

直接递归计算斐波那契数列会重复计算大量子问题。请用一个缓存装饰器把复杂度降下来。

## 任务

实现 memoize 装饰器，并计算 fib(n) 对 1,000,000,007 取模的结果。

## 输入格式

一行一个整数 n。

## 输出格式

一行一个整数，表示 fib(n) mod 1000000007。

## 样例

### 样例 1

**输入**

```text
10
```

**输出**

```text
55
```

### 样例 2

**输入**

```text
0
```

**输出**

```text
0
```

## 数据范围

0 ≤ n ≤ 200。

## 知识点

`py-decorators` · `py-functions`
