# 单词统计

> 文本处理 · 15 分钟 · 知识点：py-dict、py-list

## 情景

内容团队想了解一篇文章里哪些词出现得最多，以及用词丰富度如何。

## 任务

输出去重后的单词数量，以及出现次数最多的单词；并列时取字典序最小的。

## 输入格式

第一行 n，第二行 n 个不含空格的小写单词。

## 输出格式

一行：unique_count top_word。

## 样例

### 样例 1

**输入**

```text
6
apple banana apple cherry banana apple
```

**输出**

```text
3 apple
```

**解释**：3 个不同单词；apple 出现 3 次。

### 样例 2

**输入**

```text
3
b a c
```

**输出**

```text
3 a
```

## 数据范围

1 ≤ n ≤ 100000，单词长度不超过 30。

## 知识点

`py-dict` · `py-list`
