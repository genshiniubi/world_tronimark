# 回文句子

> 文本处理 · 12 分钟 · 知识点：py-strings

## 情景

语言社团在收集回文句子。判断时需要忽略大小写、空格和标点符号，只看字母和数字。

## 任务

判断清洗后的句子是否为回文。

## 输入格式

一行文本，可能包含空格和标点。

## 输出格式

是回文输出 YES，否则输出 NO。

## 样例

### 样例 1

**输入**

```text
A man, a plan, a canal: Panama
```

**输出**

```text
YES
```

**解释**：清洗后为 amanaplanacanalpanama，是回文。

### 样例 2

**输入**

```text
Hello, world!
```

**输出**

```text
NO
```

## 数据范围

1 ≤ 行长度 ≤ 100000。

## 知识点

`py-strings`
