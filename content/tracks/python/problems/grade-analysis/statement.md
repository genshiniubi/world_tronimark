# 成绩分析

> 科学计算 · 12 分钟 · 知识点：py-list

## 情景

老师把一次测验的成绩交给你，希望快速得到班级的整体情况。

## 任务

输出平均分（两位小数）、最高分、最低分和及格人数。

## 输入格式

第一行 n，第二行 n 个整数成绩。

## 输出格式

一行：平均分 最高分 最低分 及格人数。

## 样例

### 样例 1

**输入**

```text
5
90 80 70 60 50
```

**输出**

```text
70.00 90 50 4
```

### 样例 2

**输入**

```text
3
59 58 57
```

**输出**

```text
58.00 59 57 0
```

## 数据范围

1 ≤ n ≤ 100000，0 ≤ 成绩 ≤ 100。

## 知识点

`py-list`
