# 账单分摊

> 金融账单 · 12 分钟 · 知识点：py-functions

## 情景

朋友聚餐后需要 AA 账单。总金额之外还要加一定比例的小费，最后平均分给每个人。

## 任务

实现 split_bill(total, people, tip_percent)，返回每人应付金额。

## 输入格式

一行三个数：总金额 total、人数 people、小费百分比 tip_percent。

## 输出格式

一行一个实数，表示每人应付金额，保留两位小数。

## 样例

### 样例 1

**输入**

```text
300 3 10
```

**输出**

```text
110.00
```

**解释**：300 × 1.1 ÷ 3 = 110。

### 样例 2

**输入**

```text
100 4 0
```

**输出**

```text
25.00
```

## 数据范围

0 ≤ total ≤ 10^6，1 ≤ people ≤ 100，0 ≤ tip_percent ≤ 100。
