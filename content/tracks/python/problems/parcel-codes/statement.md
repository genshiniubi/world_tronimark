# 快递柜取件码

> 生活服务 · 12 分钟 · 知识点：py-loops、py-strings

## 情景

快递柜的取件码必须是 6 位数字。系统导入了一批历史数据，需要先找出格式正确的取件码。

## 任务

统计 6 位纯数字取件码的数量。

## 输入格式

第一行 n。第二行 n 个取件码，用空格分隔。

## 输出格式

一行一个整数，表示合法取件码数量。

## 样例

### 样例 1

**输入**

```text
5
123456 12ab56 654321 12345 000000
```

**输出**

```text
3
```

**解释**：123456、654321、000000 合法。

### 样例 2

**输入**

```text
1
12345
```

**输出**

```text
0
```

## 数据范围

1 ≤ n ≤ 100000，取件码为非空字符串。

## 知识点

`py-loops` · `py-strings`
