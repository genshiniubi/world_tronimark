# 咖啡店订单

> 商业零售 · 10 分钟 · 知识点：py-io、py-types

## 情景

街角咖啡店上线了自助点单。顾客选择咖啡、输入杯数和会员折扣，系统需要显示应付金额。

## 任务

计算订单实付金额，保留两位小数。

## 输入格式

一行三个数：单价 price、杯数 count、折扣百分比 discount。

## 输出格式

一行一个实数，保留两位小数。

## 样例

### 样例 1

**输入**

```text
18.5 2 10
```

**输出**

```text
33.30
```

**解释**：原价 37.0，打九折后 33.3。

### 样例 2

**输入**

```text
12 1 0
```

**输出**

```text
12.00
```

## 数据范围

1 ≤ price ≤ 1000，1 ≤ count ≤ 100，0 ≤ discount ≤ 100。

## 知识点

`py-io` · `py-types`
