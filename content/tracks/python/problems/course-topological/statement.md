# 课程安排

> 生活服务 · 25 分钟 · 知识点：py-graph、py-dict

## 情景

选课系统里有一些先修关系：学习课程 a 之前必须先完成课程 b。系统需要给出一个合法的学习顺序。

## 任务

输出字典序最小的拓扑序；如果存在环，输出 -1。

## 输入格式

第一行 n 和 m。接下来 m 行，每行两个整数 a b，表示 a 必须在 b 之前完成。课程编号为 1..n。

## 输出格式

一行 n 个整数，表示合法顺序；无解输出 -1。

## 样例

### 样例 1

**输入**

```text
4 3
1 2
1 3
3 4
```

**输出**

```text
1 2 3 4
```

**解释**：1 完成后 2、3 都可选，选字典序更小的 2。

### 样例 2

**输入**

```text
3 3
1 2
2 3
3 1
```

**输出**

```text
-1
```

## 数据范围

1 ≤ n ≤ 200000，0 ≤ m ≤ 200000。

## 知识点

`py-graph` · `py-dict`
