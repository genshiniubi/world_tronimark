# 天气预警

> 生活服务 · 12 分钟 · 知识点：py-conditions

## 情景

气象站需要根据温度和风力自动发布预警。规则从高到低依次判断，满足最高等级就停止。

## 任务

输出 RED、ORANGE、YELLOW 或 GREEN。

## 输入格式

一行两个整数：温度 temperature、风力 wind。

## 输出格式

一行预警等级。

## 样例

### 样例 1

**输入**

```text
36 3
```

**输出**

```text
RED
```

**解释**：温度达到 35。

### 样例 2

**输入**

```text
28 8
```

**输出**

```text
ORANGE
```

**解释**：风力达到 7。

### 样例 3

**输入**

```text
26 2
```

**输出**

```text
YELLOW
```

## 数据范围

规则：温度 ≥ 35 或风力 ≥ 10 → RED；温度 ≥ 30 或风力 ≥ 7 → ORANGE；温度 ≥ 25 → YELLOW；否则 GREEN。

## 知识点

`py-conditions`
