# 流程控制

## 你会学到
- `if / else if / else` 的多分支写法
- `for`、`while` 与循环边界
- 累加器、计数器、最大值/最小值的初始化

## 核心概念
分支题先把规则按顺序写全，再考虑合并。循环题先确定“循环变量代表什么”，再写终止条件。

```cpp
int sum = 0;
for (int i = 0; i < n; ++i) {
    int value;
    cin >> value;
    sum += value;
}
```

## 常见坑
- `if` 的顺序会影响结果，范围判断要从窄到宽或从宽到窄统一。
- 求最大值时，初始值不能随便设为 0，输入可能全是负数。
- `while (cin >> x)` 适合读到文件末尾。

## 练习建议
在纸上列出 3 组边界输入：最小、最大、特殊值，再运行程序对照。
