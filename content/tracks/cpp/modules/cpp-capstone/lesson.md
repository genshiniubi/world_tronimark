# 综合项目：库存管理器

## 你会学到
- 把命令解析成结构化操作
- 用 `map` 维护库存状态
- 处理非法操作和边界情况
- 用小函数拆分主流程

## 核心概念
综合题不要一上来写 `main`。先列出：
1. 系统状态是什么？
2. 每条命令会改变什么？
3. 失败时输出什么？

```cpp
map<string, int> stock;
if (op == "ADD") {
    stock[name] += qty;
    cout << "OK\n";
}
```

## 常见坑
- 库存不足时不能扣成负数。
- 命令参数可能包含空格，读入方式要统一。
- 输出要和题目要求完全一致。

## 练习建议
先实现 ADD/QUERY，再实现 SELL，最后补边界测试。
