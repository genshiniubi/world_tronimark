# 引用、指针与结构体

## 你会学到
- `T&` 引用和 `const T&` 只读引用
- 指针、`nullptr` 和解引用
- `struct` 与自定义比较

## 核心概念
引用是已有对象的别名，必须初始化且不能改绑；指针保存地址，可以为空，也可以指向别处。现代 C++ 中，能用引用表达“一定存在”时优先用引用。

```cpp
struct Student {
    string name;
    int score;
};
```

## 常见坑
- 不要返回局部变量的引用或指针。
- 指针使用前检查是否为 `nullptr`。
- 结构体排序时比较器要满足严格弱序。

## 练习建议
每写一个指针，先问：它指向谁？谁负责释放？生命周期够长吗？
