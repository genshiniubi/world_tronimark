# 异常安全与 RAII

## 你会学到
- 构造函数获取资源、析构函数释放资源
- `std::unique_ptr` 独占所有权
- 异常发生时也能正确清理

## 核心概念
RAII 的核心是：资源的生命周期绑定到对象生命周期。不要手动 `new/delete`，优先使用标准容器和智能指针。

```cpp
auto data = make_unique<int[]>(n);
for (int i = 0; i < n; ++i) data[i] = i;
```

## 常见坑
- `unique_ptr` 不能复制，只能移动。
- 不要用两个智能指针管理同一块裸内存。
- 析构函数不要抛出异常。

## 练习建议
把一段使用 `new/delete` 的代码改写成标准容器或智能指针。
