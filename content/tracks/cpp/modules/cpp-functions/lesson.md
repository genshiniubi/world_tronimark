# 函数与递归

## 你会学到
- 函数声明、参数、返回值
- 值传递与引用传递
- 递归的出口和递归式

## 核心概念
函数名应该是一个动词，参数表达“做这件事需要什么”，返回值表达“结果是什么”。

```cpp
long long gcd(long long a, long long b) {
    return b == 0 ? a : gcd(b, a % b);
}
```

## 常见坑
- 递归必须有出口，否则会栈溢出。
- 大整数乘法/最小公倍数要注意 `long long`。
- 修改调用方变量需要引用参数 `T&`。

## 练习建议
写完函数后，单独用几个小数据测试它，而不是只测整个程序。
