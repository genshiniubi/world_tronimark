# 成绩分析

> 科学计算 · 15 分钟 · 知识点：cpp-arrays、cpp-loops

## 情景

老师想把一次随堂测验的成绩录入系统，快速得到班级的整体情况。

## 任务

计算平均分、最高分、最低分和及格人数（≥60 分）。

## 输入格式

第一行 n，第二行 n 个整数成绩。

## 输出格式

一行：平均分（保留两位小数）、最高分、最低分、及格人数。

## 样例

### 样例 1

**输入**

```text
5
90 80 70 60 50
```

**输出**

```text
70.00 90 50 4
```

**解释**：总分 350，平均 70；及格 4 人。

### 样例 2

**输入**

```text
3
59 58 57
```

**输出**

```text
58.00 59 57 0
```

## 数据范围

1 ≤ n ≤ 100000，0 ≤ 成绩 ≤ 100。

## 知识点

`cpp-arrays` · `cpp-loops`
