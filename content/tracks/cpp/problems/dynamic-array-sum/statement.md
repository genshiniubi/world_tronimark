# 动态数组求和

> 系统工具 · 18 分钟 · 知识点：cpp-raii、cpp-pointers

## 情景

一段旧代码使用 new[] 分配数组，异常路径上容易忘记 delete[]。请把它改造成 RAII 风格。

## 任务

读入 n 个整数，使用 unique_ptr<int[]> 管理动态数组，输出总和。

## 输入格式

第一行 n，第二行 n 个整数。

## 输出格式

一行一个整数，表示总和。

## 样例

### 样例 1

**输入**

```text
4
1 2 3 4
```

**输出**

```text
10
```

### 样例 2

**输入**

```text
3
-1 5 -2
```

**输出**

```text
2
```

## 数据范围

1 ≤ n ≤ 100000，-10^9 ≤ 数值 ≤ 10^9，保证总和在 long long 范围内。

## 知识点

`cpp-raii` · `cpp-pointers`
