# 回文昵称

> 文本处理 · 10 分钟 · 知识点：cpp-strings

## 情景

社区活动要给回文昵称的用户发小礼物。运营同学需要快速判断昵称正着读和反着读是否一样。

## 任务

忽略字母大小写，判断昵称是否为回文。

## 输入格式

一行一个不含空格的字符串 s。

## 输出格式

是回文输出 YES，否则输出 NO。

## 样例

### 样例 1

**输入**

```text
Level
```

**输出**

```text
YES
```

**解释**：忽略大小写后 level 是回文。

### 样例 2

**输入**

```text
hello
```

**输出**

```text
NO
```

## 数据范围

1 ≤ |s| ≤ 100000，s 只包含英文字母和数字。

## 知识点

`cpp-strings`
