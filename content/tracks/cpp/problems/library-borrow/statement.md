# 图书馆借阅

> 生活服务 · 22 分钟 · 知识点：cpp-oop、cpp-stl

## 情景

图书馆用一个简易系统管理图书借阅。每本书有若干复本，借出时数量减一，归还时数量加一。

## 任务

实现 Library 类，处理借书和还书操作。

## 输入格式

第一行 n，表示图书种类数。接下来 n 行，每行 `id copies`。然后一行 m，接下来 m 行，每行 `BORROW id` 或 `RETURN id`。

## 输出格式

每次操作输出 OK 或 NO。借书时没有可借复本或 id 不存在输出 NO；还书时 id 不存在输出 NO。

## 样例

### 样例 1

**输入**

```text
2
1 1
2 0
4
BORROW 1
BORROW 1
RETURN 1
BORROW 2
```

**输出**

```text
OK
NO
OK
NO
```

**解释**：1 号书借出后无复本；归还后恢复；2 号书一直为 0。

## 数据范围

1 ≤ n, m ≤ 100000，0 ≤ copies ≤ 1000。

## 知识点

`cpp-oop` · `cpp-stl`
