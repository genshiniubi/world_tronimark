# 通用最大值

> 科学计算 · 14 分钟 · 知识点：cpp-templates

## 情景

实验数据处理中经常要对不同类型的序列求最大值。为了让代码复用，工程师决定写一个函数模板。

## 任务

实现函数模板 maximum，返回数组中的最大值。

## 输入格式

第一行 n，第二行 n 个整数。

## 输出格式

一行一个整数，表示最大值。

## 样例

### 样例 1

**输入**

```text
5
-3 8 2 8 1
```

**输出**

```text
8
```

**解释**：最大值是 8。

### 样例 2

**输入**

```text
1
-5
```

**输出**

```text
-5
```

## 数据范围

1 ≤ n ≤ 100000，-10^9 ≤ 数值 ≤ 10^9。
