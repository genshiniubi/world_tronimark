# 仓库库存盘点

> 商业零售 · 15 分钟 · 知识点：cpp-loops

## 情景

仓库管理员每天要盘点若干货架的库存。请写一个程序，快速汇总这批数据。

## 任务

输出库存总和、最大值、最小值和库存为 0 的货架数量。

## 输入格式

第一行一个整数 n。第二行 n 个整数，表示每个货架的库存。

## 输出格式

一行四个整数：sum max min zeroCount。

## 样例

### 样例 1

**输入**

```text
5
3 -1 0 8 2
```

**输出**

```text
12 8 -1 1
```

**解释**：总和 12，最大值 8，最小值 -1，1 个零库存。

### 样例 2

**输入**

```text
1
-5
```

**输出**

```text
-5 -5 -5 0
```

## 数据范围

1 ≤ n ≤ 100000，-1000000 ≤ 库存 ≤ 1000000。

## 知识点

`cpp-loops`
