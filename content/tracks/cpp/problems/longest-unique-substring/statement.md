# 最长无重复子串

> 文本处理 · 20 分钟 · 知识点：cpp-window、cpp-strings

## 情景

内容审核系统需要找出一个昵称中最长的“无重复字符片段”，用来做高亮展示。

## 任务

求字符串 s 中不含重复字符的最长连续子串长度。

## 输入格式

一行一个只含小写英文字母的字符串 s。

## 输出格式

一行一个整数，表示最长长度。

## 样例

### 样例 1

**输入**

```text
abcabcbb
```

**输出**

```text
3
```

**解释**：最长的是 abc。

### 样例 2

**输入**

```text
bbbbb
```

**输出**

```text
1
```

## 数据范围

1 ≤ |s| ≤ 200000。

## 知识点

`cpp-window` · `cpp-strings`
