# 朋友圈连通块

> 游戏 · 25 分钟 · 知识点：cpp-dsu

## 情景

游戏里有 n 个玩家，好友关系具有传递性：A 和 B 是好友、B 和 C 是好友，那么 A、B、C 属于同一个朋友圈。

## 任务

给定 m 对好友关系，输出朋友圈的数量。

## 输入格式

第一行 n 和 m。接下来 m 行，每行两个整数 u v，表示 u 和 v 是好友。

## 输出格式

一行一个整数，表示连通块数量。

## 样例

### 样例 1

**输入**

```text
5 3
1 2
2 3
4 5
```

**输出**

```text
2
```

**解释**：{1,2,3} 和 {4,5}。

### 样例 2

**输入**

```text
4 0
```

**输出**

```text
4
```

## 数据范围

1 ≤ n ≤ 200000，0 ≤ m ≤ 200000，1 ≤ u, v ≤ n。

## 知识点

`cpp-dsu`
