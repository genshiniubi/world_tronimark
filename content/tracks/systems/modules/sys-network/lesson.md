# 网络基础：一次请求的旅程

## 输入 URL 之后
1. 浏览器解析 URL，确定协议、域名、端口、路径
2. DNS 把域名解析成 IP
3. 与服务器建立 TCP 连接（HTTPS 还要 TLS 握手）
4. 发送 HTTP 请求
5. 服务器返回状态码、响应头和响应体
6. 浏览器渲染页面

## 常见状态码
- `200` 成功
- `301/302` 重定向
- `400` 请求格式错误
- `401/403` 未认证 / 无权限
- `404` 资源不存在
- `500` 服务端错误

## HTTP 与 HTTPS
HTTPS 在 HTTP 之下加了 TLS：它提供加密、完整性校验和身份认证。不要在没有 HTTPS 的页面里提交密码。

## 本地开发中的地址
- `127.0.0.1` 和 `localhost` 都指向本机
- `3001` 是端口，不是路径
- 前端 5173 通过代理把 `/api` 转发到 3001
