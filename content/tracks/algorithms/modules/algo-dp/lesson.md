# 动态规划入门

## 你会学到
- 状态定义与转移方程
- 初始化与遍历顺序
- 0/1 背包与空间优化

## 核心概念
动态规划 = 把大问题拆成重叠子问题，并保存子问题答案。先写清楚 `dp[i]` 的含义，再写转移。

```cpp
dp[0] = 1;
for (int i = 1; i <= n; ++i) {
    dp[i] = dp[i - 1] + (i >= 2 ? dp[i - 2] : 0);
}
```

## 常见坑
- 状态含义不清，转移一定混乱。
- 0/1 背包压缩空间时，容量要倒序遍历。
- 计数题注意取模。

## 练习建议
先用二维表手推 5 个状态，再写代码。
