# 最多不重叠区间

> 生活服务 · 20 分钟 · 知识点：algo-greedy、algo-sort

## 情景

会议室预约系统收到了一批使用申请。每场会议有一个开始和结束时间，同一时间只能安排一场。

## 任务

选择最多数量的互不重叠会议；端点相等视为可以接上。

## 输入格式

第一行 n。接下来 n 行，每行两个整数 start end。

## 输出格式

一行一个整数，表示最多会议数。

## 样例

### 样例 1

**输入**

```text
3
1 2
2 3
3 4
```

**输出**

```text
3
```

**解释**：三场会议首尾相接。

### 样例 2

**输入**

```text
4
1 4
2 3
4 6
5 7
```

**输出**

```text
2
```

## 数据范围

1 ≤ n ≤ 200000，0 ≤ start < end ≤ 10^9。

## 知识点

`algo-greedy` · `algo-sort`
