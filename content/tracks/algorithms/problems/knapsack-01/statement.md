# 0/1 背包

> 游戏 · 25 分钟 · 知识点：algo-dp、algo-complexity

## 情景

游戏角色的背包有容量限制。地上有若干物品，每件只能拿一次，每件有重量和价值。请选择一些物品，让总价值最大。

## 任务

输出不超过背包容量的最大总价值。

## 输入格式

第一行 n 和 capacity。接下来 n 行，每行 weight 和 value。

## 输出格式

一行一个整数，表示最大总价值。

## 样例

### 样例 1

**输入**

```text
3 5
2 3
3 4
4 5
```

**输出**

```text
7
```

**解释**：选择重量 2 和 3 的物品，总价值 7。

## 数据范围

1 ≤ n ≤ 2000，1 ≤ capacity ≤ 10000，1 ≤ weight, value ≤ 10000。

## 知识点

`algo-dp` · `algo-complexity`
