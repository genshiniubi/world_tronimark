# 岛屿数量

> 游戏 · 20 分钟 · 知识点：algo-graph

## 情景

一张地图由陆地和海洋组成，1 表示陆地，0 表示海洋。上下左右相连的陆地属于同一座岛屿。

## 任务

统计地图中岛屿的数量。

## 输入格式

第一行 n 和 m。接下来 n 行，每行一个长度为 m 的 01 字符串。

## 输出格式

一行一个整数。

## 样例

### 样例 1

**输入**

```text
4 5
11000
11000
00100
00011
```

**输出**

```text
3
```

### 样例 2

**输入**

```text
1 1
0
```

**输出**

```text
0
```

## 数据范围

1 ≤ n, m ≤ 1000。

## 知识点

`algo-graph`
