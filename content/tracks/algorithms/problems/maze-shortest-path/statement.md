# 迷宫最短步数

> 游戏 · 25 分钟 · 知识点：algo-graph、algo-complexity

## 情景

游戏角色从地图的 S 出发，要走到 E。地图中 # 是墙，. 是空地，每步可以上下左右移动一格。

## 任务

求从 S 到 E 的最短步数；无法到达输出 -1。

## 输入格式

第一行 n 和 m。接下来 n 行，每行一个长度为 m 的地图字符串。

## 输出格式

一行一个整数。

## 样例

### 样例 1

**输入**

```text
3 3
S..
.#.
..E
```

**输出**

```text
4
```

**解释**：S→(0,1)→(0,2)→(1,2)→E。

### 样例 2

**输入**

```text
1 2
SE
```

**输出**

```text
1
```

## 数据范围

1 ≤ n, m ≤ 1000，地图有且仅有一个 S 和一个 E。

## 知识点

`algo-graph` · `algo-complexity`
