# 爬楼梯

> 算法竞赛 · 15 分钟 · 知识点：algo-dp、algo-complexity

## 情景

一段楼梯有 n 级。你每次可以走 1 级或 2 级，想知道从地面走到第 n 级共有多少种走法。

## 任务

输出走法数量对 1,000,000,007 取模的结果。

## 输入格式

一行一个整数 n。

## 输出格式

一行一个整数，表示方案数。

## 样例

### 样例 1

**输入**

```text
3
```

**输出**

```text
3
```

**解释**：1+1+1、1+2、2+1。

### 样例 2

**输入**

```text
10
```

**输出**

```text
89
```

## 数据范围

1 ≤ n ≤ 10^6。

## 知识点

`algo-dp` · `algo-complexity`
