# 有序数组查找

> 算法竞赛 · 15 分钟 · 知识点：algo-binary、algo-complexity

## 情景

一个成绩系统保存了按分数从低到高排列的记录。现在要快速找到某个分数第一次出现的位置。

## 任务

对每个查询，输出目标值在数组中的最左下标；不存在输出 -1。下标从 0 开始。

## 输入格式

第一行 n 和 q。第二行 n 个非降序整数。第三行 q 个查询值。

## 输出格式

每个查询输出一行，表示最左下标或 -1。

## 样例

### 样例 1

**输入**

```text
5 3
1 3 5 7 9
5 1 8
```

**输出**

```text
2
0
-1
```

**解释**：5 在下标 2；1 在下标 0；8 不存在。

## 数据范围

1 ≤ n, q ≤ 200000，-10^9 ≤ 数值 ≤ 10^9。

## 知识点

`algo-binary` · `algo-complexity`
