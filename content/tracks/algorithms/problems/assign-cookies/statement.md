# 分发饼干

> 生活服务 · 15 分钟 · 知识点：algo-greedy、algo-sort

## 情景

幼儿园有一批饼干和一群孩子。每个孩子有一个胃口值，每块饼干有一个尺寸；只有尺寸不小于胃口时，孩子才会满足。

## 任务

每个孩子最多一块饼干，每块饼干最多给一个孩子，求最多能满足多少个孩子。

## 输入格式

第一行 n 和 m。第二行 n 个孩子胃口。第三行 m 个饼干尺寸。

## 输出格式

一行一个整数，表示最多满足人数。

## 样例

### 样例 1

**输入**

```text
3 2
1 2 3
1 1
```

**输出**

```text
1
```

### 样例 2

**输入**

```text
2 3
1 2
1 2 3
```

**输出**

```text
2
```

## 数据范围

1 ≤ n, m ≤ 200000，1 ≤ 值 ≤ 10^9。

## 知识点

`algo-greedy` · `algo-sort`
